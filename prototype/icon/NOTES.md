# Icon lab

Question: which menu-bar icon still means Nightshift at 16pt, in one template color?

Open with `make icon-lab`. Variants live on `?variant=`.

- A Pictogram — a sunset picture. Same at every warmth.
- B Meter — the icon shows the current warmth. Thermometer is the bulb-and-stem version of Column.
- C Mark — a moon, an N, or a sun, with no scene.
